Forumind 幫你在幾秒內跟上任何 Discourse 論壇。它是一款論壇瀏覽器，旁邊配有 AI 助理：摘要長篇話題、繼續追問，還能讓助理替你搜尋整個論壇，並附上它引用的貼文連結。

不必再逐則翻閱
不用讀完每一則貼文，就能掌握 500 則回覆的話題重點：原文內容、大家怎麼說，以及討論串裡的實用建議。之後點一下「檢查新回覆」，只會讀取新的貼文。

隨時提問
就你正在閱讀的話題聊一聊：「大家最後怎麼決定？」「有沒有替代做法？」編輯問題即可開啟新的對話分支，還能為單一話題設定專屬指示。

問論壇
提出一個問題，助理會搜尋論壇、閱讀最相關的話題，並給出附上編號來源的回答，點一下就能查證。

任何 Discourse 論壇
打開論壇，App 會自動辨識。釘選最常用的論壇，造訪過的論壇會出現在「最近」中。如果論壇需要登入，直接在 App 內登入即可。你的登入資訊只會傳送給該論壇。

從 Safari 或 Chrome 分享
將任何論壇頁面分享到 Forumind，即可在 App 中打開、產生摘要、就它聊天或問論壇。

追蹤話題
你關心的話題有新回覆時，會收到通知。

AI 由你選擇
在支援的裝置上使用 Apple Intelligence：不需要帳號，也不需要金鑰。或者用 API 金鑰連接你自己的 AI 供應商，包括許多熱門雲端服務，也可以在你自己的電腦上執行模型。

善待論壇
Forumind 預設每秒讀取一頁，絕不讓論壇伺服器負擔過重；你可以在設定中更改讀取節奏。廣告和追蹤器阻擋（EasyList 和 EasyPrivacy）是選用功能，預設關閉，以尊重仰賴廣告維持的論壇站長。在設定中開啟一個開關即可啟用。

所有裝置通用
專為 iPhone 和 iPad 打造，在 iPad 上論壇和助理可並排顯示。你的論壇、摘要、聊天和設定會透過你自己的 iCloud 帳號自動同步，並採用端對端加密。

隱私從設計開始
- 無需帳號，沒有分析，沒有廣告，沒有追蹤。
- 沒有 Forumind 伺服器。App 直接與論壇和你選擇的 AI 通訊。
- API 金鑰儲存在你的鑰匙圈中。
- 你的歷史記錄只保存在你的裝置和你自己的 iCloud 中。
