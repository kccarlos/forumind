Forumind 帮你在几秒内跟上任何 Discourse 论坛。它是一款论坛浏览器，旁边配有 AI 助手：总结长篇话题、继续追问，还能让助手替你搜索整个论坛，并附上它引用的帖子链接。

不必再逐帖翻阅
无需读完每一楼，就能掌握 500 条回复的话题要点：原帖内容、大家怎么说，以及帖子里的实用建议。之后轻点“检查新回复”，只会读取新的帖子。

随时提问
就你正在阅读的话题聊一聊：“大家最后怎么决定的？”“有没有变通办法？”编辑问题即可开启新的对话分支，还能为单个话题设置专属指令。

问论坛
提出一个问题，助手会搜索论坛、阅读最相关的话题，并给出附带编号来源的回答，轻点即可核对。

任何 Discourse 论坛
打开论坛，App 会自动识别。置顶最常用的论坛，访问过的论坛会出现在“最近”中。如果论坛需要登录，直接在 App 内登录即可。你的登录信息只会发送给该论坛。

从 Safari 或 Chrome 分享
把任何论坛页面分享到 Forumind，即可在 App 中打开、生成摘要、就它聊天或问论坛。

关注话题
你关心的话题有新回复时，会收到通知。

AI 由你选择
在支持的设备上使用 Apple 智能：无需账户，也无需密钥。或者用 API 密钥接入你自己的 AI 提供方，包括许多热门云服务，也可以在你自己的电脑上运行模型。

善待论坛
Forumind 默认每秒读取一页，绝不给论坛服务器造成负担；你可以在设置中更改读取节奏。广告和跟踪器拦截（EasyList 和 EasyPrivacy）是可选功能，默认关闭，以尊重依靠广告维持的论坛站长。在设置中打开一个开关即可启用。

所有设备通用
专为 iPhone 和 iPad 打造，在 iPad 上论坛和助手可并排显示。你的论坛、摘要、聊天和设置会通过你自己的 iCloud 账户自动同步，并采用端到端加密。

隐私从设计开始
- 无需账户，没有分析，没有广告，没有跟踪。
- 没有 Forumind 服务器。App 直接与论坛和你选择的 AI 通信。
- API 密钥保存在你的钥匙串中。
- 你的历史记录只保存在你的设备和你自己的 iCloud 中。

免费且开源
Forumind 免费并以 Apache License 2.0 开源。如果你使用自己的 AI 提供方，该提供方可能会按用量向你收费。
